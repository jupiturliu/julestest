# Greedy Snake Game

## Description
A classic implementation of the Greedy Snake game using Python and the Pygame library. The player controls a snake that grows by eating food items. The game ends if the snake hits the window boundaries or its own body.

## Features
- Classic snake gameplay
- Increasing difficulty (snake speed increases with score)
- Score tracking
- Option to play again after game over

## Requirements
This game requires Python and Pygame.

To install the necessary Pygame library, you can use pip with the provided `requirements.txt` file:
```bash
pip install -r requirements.txt
```

## How to Run
1.  Ensure you have Python and Pygame installed (see Requirements).
2.  Clone this repository or download the `snake_game.py` and `requirements.txt` files.
3.  Navigate to the directory containing the files in your terminal.
4.  Run the game using the following command:
    ```bash
    python snake_game.py
    ```

## Controls
-   **Arrow Keys**: Control the direction of the snake (Up, Down, Left, Right).
-   **C**: Play Again (after a game over).
-   **Q**: Quit the game (either during gameplay or at the game over screen).
